# Original Sargon (Z80)

`sargon-z80.asm` is the 1978 Sargon chess program by Dan and Kathe Spracklen,
in standard Z80 mnemonics, from Bill Forster's retro-sargon project
(<https://github.com/billforsternz/retro-sargon>, file `stages/sargon-z80.asm`).

It is kept unchanged here as the reference for the ports:
- `..\Sharp_PC_G850VS\sargon-g850.asm` was made from it;
- `SargonSim` plays the same games through both and checks that Sargon chooses the
  same moves (see `..\Sharp_PC_G850VS\README.md`).
